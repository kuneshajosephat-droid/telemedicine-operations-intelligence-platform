📊  Interactive Dashboard

This project includes an interactive Streamlit-based analytics dashboard for telehealth insights.

🔹 Key Features
1. KPI Metrics
Total Enrollment
Total Telehealth Users
Average Telehealth Rate

👉 Example ( dashboard):

595M+ enrollment
188M+ telehealth users
33.31% average rate
2. Trend Analysis
Telehealth adoption over time
Change between years

👉 Example:

Drop from 48.91% (2020) to 25.46% (2024)
3. Machine Learning Forecast
Model comparison:
Linear Regression
Random Forest

👉 Result:

Random Forest performs better (lower MAE)
Future predictions up to 2027
4. Regional Insights
Top performing regions
Lowest performing regions
Adoption gap analysis

👉 Example:

Adoption gap ≈ 21.27 percentage points
5. Equity & Distribution Analysis
Distribution of telehealth adoption across regions
Identification of at-risk regions
6. Live API Prediction
Users input:
Year
Region
Enrollment
Telehealth users
API returns:
Forecasted telehealth rate
Current calculated rate

👉 Example:

Forecast: 23.24%
Current: 25.00%
🔹 Technologies Used
Streamlit (frontend)
Plotly (visualization)
AWS Athena (data querying)
FastAPI (model API)
Python (data processing & ML)
